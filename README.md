# Proyecto Spring Boot - UPN

## Descripción
Este es un proyecto desarrollado como parte de las actividades académicas o de investigación. El documento detalla la información básica y las tecnologías principales utilizadas en su construcción.

## Tecnologías Utilizadas
* **Framework:** Spring Boot
* **Lenguaje:** Java

## Autor
* **Nombre:** Hanssel Flores
* **Institución:** Universidad Privada del Norte (UPN)

## Requisitos Previos
* Java Development Kit (JDK) instalado.
* IDE compatible con Java y Spring Boot (ej. IntelliJ IDEA, Eclipse, VS Code).
* Maven o Gradle (dependiendo de la configuración del proyecto).

## Instalación y Ejecución
1. Clona este repositorio en tu máquina local.
2. Abre el proyecto en tu IDE preferido.
3. Espera a que se descarguen las dependencias.
4. Ejecuta la clase principal de la aplicación Spring Boot para iniciar el servidor local.
